# AI Polygon

An open, architecture-neutral AI research playground. The public alpha demonstrates independent training/prediction projects, deterministic synthetic benchmarks, provenance, and a static results dashboard. It does **not** evaluate frontier models, offer free GPU training, or provide a secure blind benchmark.

The complete repository is being assembled in this commit series. See `CONTRIBUTING.md` for the research protocol and `vercel.json` for zero-secret static deployment.
